# doc-verify

Vision-led multimodal verification of study-abroad application documents (COMP6001 final project, University of
Adelaide).

The project has two parts:

- **Document type.** A ViT-B/16 image encoder is fused with frozen CLIP text features of the page's OCR text through
  cross-attention, and trained to classify Tobacco3482 scans by document type.
- **Consistency.** The same model is trained to detect internal inconsistencies in **SAD-Syn**, a synthetic dataset
  of offer letters, transcripts and bank statements built for this project, and compared against image-only, text-only
  and rule-based benchmarks.

## Reproducibility

- **Without a GPU.** Every number in the report's results is reproduced from `results/`. `03_evaluate` asserts that
  they match the report.
- **Re-predicting.** Re-predicting from the released checkpoints gives the same type predictions and authenticity
  scores equal to within fp16 rounding.
- **Retraining.** Retraining is not bit-exact: cuDNN and fp16 are non-deterministic, even with seed 42. Retrained
  runs land close to, but not exactly on, the reported numbers.
- **Rebuilding the data.** OCR depends on the Tesseract version. The report used Tesseract 5.5.2, while Colab's
  `apt` package is 4.1, so rebuilt OCR text differs slightly. The committed manifests and the bundle's text are the
  reference.
- **Test-set lock.** The test split was locked in code (`TEST_SET_UNLOCKED` in `src/doc_verify/config.py`) until
  the test plan (`reports/test_plan.md`) and thresholds were committed (`68d7058`). It was then evaluated once
  (`ed4b83f`, `9d61007`).

## Local setup

```bash
uv sync                      # create .venv and install everything (Python 3.12)
uv run jupyter lab           # notebooks
uv run pytest                # tests: generator rules, text-window coverage
uv run python scripts/build_sad_syn.py    # rebuild SAD-Syn (3,000 pages, ~5 min on 10 cores)
uv run python scripts/build_tobacco.py    # OCR and split Tobacco3482 (~9 min)
uv run python scripts/prepare_colab.py    # pack the 224 x 224 data bundle
```

Requires Tesseract 5 on the system (`brew install tesseract`).

## Layout

- `notebooks/` – the three submission notebooks; `development/` holds the working notebooks they were distilled from
  (calibration experiments, the original Colab training notebook, the test run under the frozen plan)
- `src/doc_verify/` – data, models, training and evaluation:
  - `config.py` – paths, split, seed, shared manifest columns, the test-set lock
  - `tobacco.py` – Tobacco3482: pinned download, 200 DPI pages, OCR, stratified 70/15/15 split, manifest
  - `text_length.py` – OCR text length in CLIP tokens; where the evidence for a planted mistake falls
  - `windows.py` – overlapping CLIP token windows (75 tokens, stride 50, 8 windows) and the frozen CLIP feature cache
  - `data.py` – combined page table with masked labels (type / authenticity / kind), the PyTorch dataset
  - `models.py` – fused ViT-B/16 + CLIP-text cross-attention model, image-only ViT and ResNet18 baselines
  - `train.py` – masked multi-task loss, AdamW, early stopping on validation, prediction
  - `evaluate.py` – metrics, pair-bootstrap intervals, breakdowns, thresholds, confusion matrices, McNemar
  - `checks.py` – pre-test sanity checks: labels vs generated documents, evidence inside the text windows, cache
    alignment
  - `baselines.py`, `rule_checker.py` – TF-IDF + logistic regression, CLIP zero-shot, rule checker on OCR values
  - `assets.py` – downloads the data bundle and checkpoints from the GitHub release
- `sad_syn/` – the synthetic dataset generator:
  - `generate.py`, `transcript.py`, `bank_statement.py` – fields, one-rule inconsistencies and consistency rules for
    offer letters, transcripts and bank statements
  - `doc_types.py` – registry so the pipeline treats every type the same way
  - `templates.py` – seeded generator of 20 templates per type; split 14/3/3 by template
  - `layout.py`, `render.py` – page drawing (wrapping, tables, overflow check) and renderers
  - `degrade.py` – label-blind scan degradation with a per-page strength and an ink-fraction check
  - `ocr.py` – OCR, word confidence, checks that printed values were read
  - `pipeline.py` – render → degrade → OCR for many documents in parallel
  - `dataset.py` – paired clean/altered dataset plan and build: images, OCR text, `manifest.csv`
  - `analysis.py` – calibration against Tobacco3482, label-gap tests, effect ablations, font screening
- `results/` – committed outputs: manifests, test and validation predictions, training logs of the six runs
- `reports/` – the frozen test plan and thresholds, test result tables, figures, report drafts
- `tests/` – pytest: every generated document breaks exactly its intended rule; any value up to 26 tokens sits whole in
  one text window
- `scripts/` – command-line entry points (see Local setup)
- `fonts/` – bundled fonts and their licences; only fonts that passed the OCR font screen are used
- `data/`, `models/` – local data and checkpoints (git-ignored)
